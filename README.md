# Revit Family Importer

A Revit add-in by **Arshad Paloli** to browse and load families from a project file or a folder into the active Revit model.

- Supports **Revit 2025 and 2026**
- Browse by thumbnail and category, search, favourites
- Load from a project (.rvt) or a folder of .rfa files
- Light/dark theme follows Revit's UI theme
- Add-in appears on the **Add-ins** tab, in the *Family Tools* panel

## Download

Download **FamilyImporter-Setup-1.0.6.exe** from the [latest release](https://github.com/arshad-paloli/Revit-Family-Importer/releases/latest).

## Install

1. Close Revit.
2. Run the installer (no admin rights needed).
3. Start Revit and open **Add-ins → Family Tools → Importer**.

> The installer is not code-signed, so Windows SmartScreen shows "Unknown publisher". Click **More info → Run anyway**.

## Notes

Opening a project saved in an older Revit makes Revit upgrade it in memory, which can take several minutes. Your file is never modified.
